### Issue 1: Critical - 200 Status Override Masking Genuine NotFound

**Location:** `crates/pds/src/read_after_write/mod.rs` lines 418-422

**Root Cause:** The status override was firing on `is_thread_not_found` alone, without confirming that the munged output actually contained a reconstructed thread. This meant a genuine NotFound whose requested_uri was NOT a local post would be returned as HTTP 200 carrying the AppView's error body, violating the lexicon.

**Fix Applied:** Added a check for actual reconstruction:
```rust
let reconstructed = munged.get("thread").map(|t| !t.is_null()).unwrap_or(false);
let response_status = if is_thread_not_found &amp;&amp; status.is_client_error() &amp;&amp; reconstructed {
    axum::http::StatusCode::OK
} else {
    status
};
```

Now the override only applies when:
1. `is_thread_not_found` (the AppView returned a 400 NotFound for getPostThread)
2. `status.is_client_error()` (original was a 4xx)
3. **AND** `reconstructed` (the munged output has a non-null thread field)
