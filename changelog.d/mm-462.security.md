Wallet Keychain items now live in a stable access group (`org.obsign.shared`) that does not
track the iOS bundle identifier, with the previous implicit group still declared so anything
written before this release stays readable. Until now the bundle id silently doubled as both
the Keychain access group and the iCloud container id, so renaming it would have made every
device key, recovery share, session, and backup unreachable with no error shown. The iCloud
container id is now frozen permanently, and a CI gate refuses a bundle-id change that arrives
without the migration (ADR-0030).
